# Media sources

Video clips in `public/media` and the invoice photos in `lib/invoices/car-images.ts` come from two libraries. `lib/media-clips.ts` says which page plays which clip.

## Coverr

[Coverr](https://coverr.co)'s licence allows free commercial use without credit. It forbids redistributing the clips as a competing library, and it doesn't cover brands visible in a clip, so check for logos before using a clip anywhere prominent.

| File | Coverr clip |
|---|---|
| `paint-booth` | coverr-mechanic-working-on-a-car-953 |
| `panel-repair` | coverr-man-hammering-a-car-piece-4161 |
| `jet-wash` | coverr-washing-car-with-a-jet-5415 |
| `car-wash-inside` | coverr-pov-car-wash-9339 |

## Mixkit

[Mixkit](https://mixkit.co) clips are each under its Stock Video Free License, which its pages describe as for "commercial or personal use". Check the licence before redistributing a clip on its own.

| File | Mixkit clip |
|---|---|
| `engine-repair` | mechanic-repairing-a-car-engine-4716 |
| `oil-service` | mechanic-pouring-oil-into-an-engine-41937 |
| `parked-car`, invoice background | parked-red-sports-car-66 |
| `open-road` | a-red-sports-car-traveling-along-a-curvy-asphalt-road-52427 |
| invoice header | red-sports-car-side-view-50 |

Many other Mixkit car clips are under its Restricted License, which is personal use only. Don't use those here. Each clip's page shows which licence applies.
